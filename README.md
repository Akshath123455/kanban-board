# 📋 Kanban Board

A modern, responsive, and fully functional Kanban board application built with vanilla HTML, CSS, and JavaScript. Manage your projects and tasks efficiently with intuitive drag-and-drop functionality, advanced filtering, dark/light mode support, and local storage persistence.

## ✨ Features

- **🖱️ Native Drag & Drop**: Seamlessly move tasks between columns (To Do, In Progress, Review, Done) using the HTML5 Drag and Drop API.
- **📝 Full CRUD Operations**: Create, read, update, delete, and duplicate tasks with ease.
- **🔍 Advanced Filtering & Sorting**: Filter tasks by assignee, priority, and status. Sort by newest, oldest, priority, due date, or alphabetically.
- **🌓 Dark / Light Mode**: Toggle between themes with a smooth transition. Your preference is automatically saved.
- **💾 Local Storage Persistence**: All tasks and theme preferences are saved locally, ensuring your data persists across page reloads.
- **📊 Real-time Statistics**: A dashboard overview displaying total, in-progress, in-review, and completed task counts.
- **🏷️ Rich Task Details**: Support for task titles, descriptions, priority levels (Urgent, High, Medium, Low), assignees, due dates, and custom tags.
- **🔔 Toast Notifications**: Clean visual feedback for user actions like creating, updating, moving, or deleting tasks.
- **📱 Responsive Design**: A clean, modern UI with subtle shadows, hover effects, and smooth transitions that works beautifully across desktop and mobile devices.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and native Drag & Drop API.
- **CSS3**: Modern styling with CSS Custom Properties (Variables) for seamless theming, Flexbox/Grid layouts, and responsive design.
- **Vanilla JavaScript**: Zero dependencies. Pure JavaScript handles all application logic, DOM manipulation, and `localStorage` management.
